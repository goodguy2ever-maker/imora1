# IMORA 2.0 — Часть 3: Workspace & Construction Domain Logic

Данный модуль отвечает за рабочее пространство компании:
1. Архитектурный 2D-редактор планировок стен и экспликации помещений (`DrawingEditorPage`).
2. Сметный модуль (`ProjectDetailPage`): версионность смет, расчёт стоимости по строкам, утверждение бюджетов.
3. Модуль снабжения (`MaterialsPage`): заявки на материалы с цепочкой согласования.
4. Контроль финансов (`ExpensesPage`): план-факт анализ затрат.
5. Отчёты прорабов (`ReportsPage`): ежедневный журнал выполненных работ со стройплощадки.
6. Задачи и команда (`TasksPage`, `TeamPage`).
