# IMORA 2.0 — Часть 2: Core Platform, Auth, Access & Billing

Данный модуль отвечает за:
1. Авторизацию и профили пользователей (Supabase Auth).
2. Ролевую модель (SUPER_ADMIN платформы, COMPANY_ADMIN компании, MEMBER сотрудник).
3. Биллинг и эквайринг (Stripe / ЮKassa / CloudPayments).
4. Управление тарифами и лимитами пользователей.
5. Управление воркспейсами компаний (создание компании, дата истечения доступа, аудит действий).
